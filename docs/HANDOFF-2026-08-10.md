## 3. 코드 지도 (benchmarks/eval/)

**현행 = run2 계열.** v1 파일(run.py, variants.py, oracle.py, script.py, report.py)은 배너로 표시된 구 하네스 — 건드리지 말 것.

| 파일 | 책임 | 계층 |
|---|---|---|
| `config.py` | env·상수 전부 (MAX_CONTEXT=45000, NPC_NAME=당채련, NPC_EVENT_TURN=40 등) | 최하층 (os/pathlib만) |
| `prompts.py` | 프롬프트 8종 + `active()` + `override_from(path)` | config만 |
| `director.py` | 디렉터 LLM 타입 | — |
| `transport.py` | key()·mk_llm()·call_upstream()·재시도, `SUMMARY_MODEL` | config+director |
| `hypa.py` | HypaV3 포팅 (hypa_step 5-tuple) | config+transport |
| `windowing.py` | 토큰 카운트·트림·창 판정 (tiktoken만) | 리프 |
| `quality.py` | 리롤·루프 게이트 (difflib/re만) | 리프 |
| `run2.py` | 오케스트레이션+CLI만 (474줄). run_once → `_play_turn`/`_record_probe`/`_collect_totals` | 최상층 |
| `report2.py` / `viewer.py` | 결과 집계 (LITM/eviction 2×2) / 뷰어 | 소비자 |

**패치 표면 규약 (테스트 작성 시 필독)**: 실업스트림 스텁은 `transport.call_upstream` 패치 또는 run_once `call_fn` 주입. `_key`/`make_*_llm`은 run2 별칭 경유라 `run2.` 쪽 패치. **run2.py:47-56 주석이 정본.** 교훈: 오버라이드가 도달해야 하는 호출부는 `module.NAME` 점 접근 (import-시점 별칭 = 스냅샷).

**A/B**: `--prompts ab.json` (이름→전문 JSON, 미지 키 즉시 에러), 결과 JSON `prompt_set`에 사용 프롬프트 박제. 유저 코멘트: 나중엔 langsmith/langfuse로 대체 가능성 — 지금은 자작으로 충분.

## 4. 실행 방법

```bash
# 반드시 -m 모듈 실행 (직접 실행은 import 깨짐)
python3 -m benchmarks.eval.run2 "$PRESET" "$CARD" {dreaming|vanilla|trim|hypa} \
  --session S [--runs N] [--turns N] [--trim-tokens N] [--probe-every N] \
  [--reroll-at ...] [--edit-at ...] [--ttl-wait] [--reset] [--prompts ab.json]
```
- PRESET = `/Users/yanghyeon-u/Downloads/뮈토스6.2/🏺뮈토스 프롬프트 V6.2/🏺뮈토스 프롬프트 - DeepSeek V6.2_preset.risup`
- CARD = `dreaming_data/eval/card-soyeon-v2.json`
- 테스트/린트: `python3 -m pytest -q` (663 passed), `python3 -m ruff check benchmarks/eval/ dreaming/`

**야간런**: `scripts/night_run.sh` — 4변형 병렬, 기본 100턴@32K (`TURNS`/`TRIM_TOKENS`/`SESSION_PREFIX` env로 조정). dreaming은 6턴 스모크 후 격리 0건일 때만 본런 (night2-drm-r0 사고 재발 방지). 프록시 기동·키 로딩 스크립트 내장. `caffeinate -is`와 함께 돌릴 것.

## 7. 알려진 함정

- `python3 benchmarks/eval/run2.py` 직접 실행 → ModuleNotFoundError. 항상 `-m`.
- 격리(quarantine) = 지문 미정렬 턴 원문 보관. 3턴 연속이면 자동 재베이스라인으로 자기치유 — 스모크에서 0건이면 정상.
- hypa `hypa_step`은 원본 버그 보존이 스펙 (plan_batches 등) — "고치면" 충실도 위반.
- report2/viewer는 결과 JSON 계약 소비자 — run2 결과 필드 바꾸면 같이 확인.
